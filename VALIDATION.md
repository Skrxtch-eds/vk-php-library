Тесты проверяют обработку ответов и повторов через подставной HTTP-клиент. У cURL проверены входные ограничения, но не TLS и сетевой обмен с VK. Процент покрытия отражает выполненные строки, а не отсутствие ошибок.

Под Windows инструменты запущены на копии исходников в папке с латинским путём и вне ограничений sandbox. Иначе PHP некорректно проверяет права чтения, а дочерние процессы PHPStan искажают кириллические пути. После публикации на GitHub проверки также успешно выполнены в CI на Linux и PHP 8.1–8.5.

Для повторения:

```bash
composer install
composer validate --strict
composer check
XDEBUG_MODE=coverage composer coverage
composer audit
```

Первый раунд ревью находится в `review/ADVERSARIAL_REVIEW.md`, второй в `review/ADVERSARIAL_REVIEW_ROUND_2.md`. Все найденные в обоих раундах ошибки исправлены, включая P3 с переполнением `chat_id`. Результаты повторной проверки описаны в `review/FIX_VERIFICATION.md`. Открытых находок из этих ревью не осталось; это не гарантия отсутствия любых других дефектов.
